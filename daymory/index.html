Daymory – Updates

Jede Version von Daymory, die neueste zuerst – mit Datum, Versionsnummer, neuen Funktionen und Fehlerbehebungen.

Daymory ist noch nicht veröffentlicht.

  1. Version 0.75.1 · 28.10.2026

    Neue Funktionen

    • Im Archiv ist die laufende Tour gekennzeichnet und zeigt Distanz, Dauer und Aufstieg laufend. Eine unterbrochene Tour ist als offen gekennzeichnet.

    Fehlerbehebungen

    • Es konnte vorkommen, dass der Aufstieg während einer Tour lange fehlte und erst später nachkam. Das ist behoben: Er kommt laufend aus dem Höhenmodell, wie die Distanz – auch auf dem Sperrbildschirm und in der Dynamic Island.
    • Es konnte vorkommen, dass eine gespeicherte Tour mit einer geraden Linie von einem früheren Ort begann und deshalb eine zu lange Strecke zeigte. Das ist behoben: Die Linie ist ausgeblendet, und die Strecke ist ohne sie gerechnet. Gespeichert bleibt die Tour, wie sie war.
    • Es konnte vorkommen, dass eine einzige beschädigte Tour alle Touren verbarg. Das ist behoben: Die übrigen erscheinen, und die App sagt, dass eine Tour nicht gelesen werden konnte.

  2. Version 0.75.0 · 27.10.2026

    Neue Funktionen

    • Jede Tour zeigt Aufstieg und Abstieg aus einem Höhenmodell, ein Höhenprofil, die Höhe am Start und am Ziel, den höchsten und den tiefsten Punkt, die Geschwindigkeiten und die Luftlinie.
    • Nach einem Update zeigt ein Fenster, was neu ist, und im Profil steht der Versionsverlauf.

    Fehlerbehebungen

    • Es konnte vorkommen, dass eine neue Tour an einem früheren Ort begann und von dort eine gerade Linie zog. Das ist behoben.
    • Es konnte vorkommen, dass die Karte beim Start einer Tour die ganze Welt zeigte. Das ist behoben.
    • Es konnte vorkommen, dass bei einer Tour «Aufstieg 0 m» stand, obwohl es bergauf ging. Das ist behoben.
    • Es konnte vorkommen, dass Karten beim Öffnen etwas länger brauchten, bis sie fertig gezeichnet waren. Das ist behoben.
